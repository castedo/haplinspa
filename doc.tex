\section{Definition}

A \emph{haploid lineage tree process} is a \emph{stochastic process},
which has an underlying probability space $(\Omega, \mathcal{F}, P)$,
along with the following underlying fixed givens:

\begin{enumerate}
\item a set of \emph{potential haploids}, denoted $\Hap$,
\item a \emph{time function}, denoted $\At$, mapping $\Hap$ to $\Re$,
\item a set of chromosomal loci, denoted $\Loc$, and
\item a set of real times $\Time \subset \Re$.
\end{enumerate}

Depending on the application, potential haploids might be interpreted as potential organisms, gametes, or spores.

\subsection{Haploid lineages}

A \emph{haploid lineage} represents all the haploids transmitting genetic information at a
genomic locus to a descendant haploid.

Formally, a \emph{haploid lineage} is a set of haploids, $L \subset \Hap$, such that,
with the ordering induced by $\At$, $L$ is
\begin{enumerate}
\item totally (linearly) ordered,
\item strictly ordered, and
\item every subset of $L$ has a maximum (newest) haploid.
\end{enumerate}

The set of all such \emph{haploid lineages} is denoted $\Haplin$.

The maximum (newest) haploid in a haploid lineage $L$ is denoted $\Tip(L)$.
Let $\Pred(\ell, h)$ denote $\Tip(\Lin(\ell, h) / \{h\})$, that is, the predecessor
haploid of $h$ from which genetic information was copied at locus $\ell$.

For any haploid lineage $L \in \Haplin$, a subset $S \subset L$ is a \emph{sublineage} of $L$ iff
\[
\forall x \in L, y \in S: \At(x) < \At(y) \implies x \in S
\mathstop
\]

For convenience, let $\At(L) = \At(\Tip(L))$ for any lineage $L$.


\subsection{Tree process}

A set of haploid lineages $T \subset \Haplin$ is a \emph{haploid tree} iff for every member lineage $L \in T$, every sublineage of $L$ is also a member of $T$.

The \emph{union} of a haploid tree $T$ is the union of all its member lineages, denoted
$\bigcup T$.

A \emph{haploid lineage tree process} is a family of haploid tree-valued random variables,
index by time (with subscript) and locus (with superscript),
\[
\{ \Tree^\ell_t : t \in \Re, \ell \in \Loc \}
\]
such that
\begin{enumerate}
\item $\forall t \in \Time \left( \left| \{ \bigcup \Tree^\ell_t : \ell \in \Loc \} \right| = 1 \right)$
      and thus $\bigcup \Tree_t$ is an unambiguous set of haploids,
\item $\forall t \in \Time, h \in \bigcup \Tree_t \left( \At(h) \le t \right)$, and
\item for every $\ell \in \Loc$, $\{ \Tree^\ell_t : t \in \Re \}$ has a total increasing ordering
under set inclusion order.
\end{enumerate}

As a stochastic process, a haploid lineage tree process is a time-indexed random variable taking values in the
range of functions from loci $\Loc$ to haploid trees.

Let $\bigcup \Tree$ denote $\bigcup_{t \in \Time} \bigcup \Tree_t$.

For all $h \in \bigcup \Tree$,
$\Lin(\ell, h)$ equals the $L \in \Tree^\ell_{\At(h)}$ such that $\Tip(L) = h$.


\section{Related definitions}

\subsection{Kingman $n$-coalescent}

The Kingman $n$-coalescent \cite{kingman_coalescent_1982} is defined
as a stochastic process terminating at a sample of haploids.
As a time-indexed random variable, the $n$-coalescent takes values
as equivalence relations (partitions) on the samples.

Given a fixed locus $\ell \in \Loc$, and a sample population $S \subset \Hap$,
where for some time $z \in \Time$, for all $a \in S$, $z = \At(a)$,
a haploid lineage tree process defines a backward-time-indexed random
variable $X_r$ that takes the same values as the Kingman $n$-coalescent, but not necessarily
with the same probability distribution.
The value of $X_r$ with $r \in [0, \infty)$ (in reverse time)
is the equivalence relation defined by
\[
  \left\{ (a,b) \in S^2 : \At(\Lin(\ell, a) \cap \Lin(\ell, b)) \ge (z - r) \right\}
\]


\subsection{King genealogy tree processes}

King \cite{king_exact_2026} extends the genealogical tree structure of the Kingman
$n$-coalescent, but with some differences:
\begin{enumerate}
  \item samples need not be at the same time,
  \item partitions are used instead of equivalence relations,
  \item time is indexed forwards, not backwards, and
  \item time zero is fixed to the root of the genealogical tree.
\end{enumerate}

Given a fixed locus $\ell \in \Loc$, a sample population $S \subset \Hap$, a haploid
lineage tree process defines a \emph{shifted} forward-time-indexed random variable
$Z_s$ that takes the same values as the genealogy tree structure in
\cite{king_exact_2026}.
The time index for $Z_s$ is relative to the root time $R \in \Time$, which is
\[
  R := \At\left( \bigcap_{a \in S} \Lin(\ell, a) \right)
\]
and is itself a random variable. With ancestral lineages at time $t$
of the samples $S$ denoted
\[
  A(t, S) := \{ (\infty, t] \cap \Lin(\ell,a) : a \in S \}
\mathstop
\]
we have
\[
  Z_s = \left\{ \{ a : L \subset \Lin(\ell,a) \} : L \in A(R + s, S) \right\}
\]
as the tree structure process in \cite{king_exact_2026}.


\subsection{Ancestral Recombination Graph (ARG)}

An ancestral recombination graph \cite{friedman_ancestral_1997}
\cite{hein_gene_2005} \cite{wakeley_coalescent_2009} of a sampled
population is embedded in any outcome of any haploid lineage tree process.
We formally show the
exact embedding using the gARG formalism \cite{wong_general_2024}.

We start by defining the \emph{genetic legacy} of an ancestral haploid
$h \in \Hap$ for a sample population $S \subseteq \Hap$ to be
\[
  \Lega(h, S) := \{ (\ell, d) \in \Loc \times S : h \in \Lin(\ell, d) \}
\mathstop
\]

This genetic legacy is the genetic material that survives in the
sample population $S$ originally copied from ancestral haploid $h$
(with or without mutations).

Genetic legacy for a sample population $S$ induces the following
equivalence relation over pairs of haploids $h_1$ and $h_2$ in
$\Hap$:
\[
h_1 \simeq_S h_2 \ := \ \Lega(h_1, S) = \Lega(h_2, S)
\mathstop
\]
We denote the resulting equivalence class containing $h \in \Hap$ as
\[
{[h]}_S \ := \ \{ h' : \Lega(h', S) = \Lega(h, S) \}
\mathstop
\]

In this equivalence relation, haploids are considered equivalent if
they have the same genetic legacy for the sample population $S$.

A convenient choice for an embedded gARG \cite{wong_general_2024} is
to set the gARG nodes (vertices) to be the equivalence classes:
\[
   \Nodes(S) := \{ {[h]}_S : h \in \Hap \}
\mathstop
\]

The (unannotated) graph edges of the gARG are chosen as child-parent
node pairs $(C, P) \in \Nodes(S)^2$ where
\[
  \Pred(\ell, h) \in P \text{ for some $h \in C$ and some $\ell \in \Loc$ .}
\]

In the gARG, annotations are added for each graph edge (pair of child
and parent nodes). This annotation is the set of locations through which
genetic information has been copied from parent to child. In the
following interpretation, the only locations of interest are those for
which genetic information has been transmitted into the sample
population $S$. With this interpretation, the annotation for edge
$(C,P)$ is
\[
  \{ \ell \in \Loc :
     C \subseteq \Lin(\ell, h) \text{ and } P \subseteq \Lin(\ell, h) \text{ for some $h \in S$}
  \}
\mathstop
\]
