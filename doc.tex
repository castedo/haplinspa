\begin{abstract}
This document mathematically defines a type of stochastic process: a \emph{Haploid
  Lineage Population Process}.
It explicitly models a biological process that generates empirical genetic data
  transmitted via lineages of haploid cells in a reproducing population.
In contrast to the Kingman $n$-coalescent,
  which is defined backward in time from a given set of haploid samples,
  a Haploid Lineage Population Process generates haploid samples forward in time,
  akin to a branching process.
\end{abstract}


\section{Introduction}

A \emph{stochastic process}~\cite{ash_probability_2000, pishro_nik_2014} is a
mathematical model from probability theory that is widely used in many fields of applied
mathematics.
It consists of an indexed family of \emph{random variables}, typically with
time as the index.
This document defines random variables whose values clearly model a biological
phenomenon. The focus is on defining the structure and values of these random variables,
but not specifically their probabilities.
They can serve as a general model from which many specialized models can define
specific probabilities, such as the Kingman $n$-coalescent.
Some motivations for such an underlying basis include:
\begin{itemize}
  \item better understanding and evaluation of the assumptions linking mathematical and
    biological models, and
  \item deriving different mathematical results under different mathematical conditions.
\end{itemize}

The random variables in the \nameref{sec:definitions}~section model gene genealogies
\cite{wakeley_coalescent_2009} per locus across the genomes of haploid cells.
After the definition,
the \nameref{sec:related-work}~section specifies the exact mathematical correspondences to
\begin{itemize}
  \item the Kingman $n$-coalescent \cite{kingman_coalescent_1982},
  \item the genealogical tree structure defined by King et al.~\cite{king_exact_2026}, and
  \item the genome Ancestral Recombination Graph (gARG) in Wong et al.~\cite{wong_general_2024}.
\end{itemize}


\section{Definitions}
\label{sec:definitions}

A \emph{haploid lineage process} is a \emph{stochastic
process}~\cite{ash_probability_2000, pishro_nik_2014}, which is a family of random
variables indexed by a set, typically representing time.

The features required of a haploid lineage process are based on three givens:
\begin{enumerate}
\item a set $\Time \subseteq \R$,
\item a measurable space of chromosomal loci, denoted $\Loci$, and
\item a measurable space of "birthplaces", denoted $\Places$.
\end{enumerate}

We define a space of potential haploids as
\[
\Haps := \Time \times \Places
\]
and a "birth" time function mapping $\Haps$ to $\R$ as
\[
  \Birth((t,x)) := t
\]

Depending on the application, potential haploids might describe potential organisms, gametes, or spores.

The index set of a haploid lineage process can be viewed as time, but it is more
convenient to treat its index set as $\Loci \times \Haps$, which contains $\Time$ as
a sub-index.


\subsection{Haploid Lineage}

A \emph{haploid lineage} represents all the haploids transmitting genetic information at a
genomic locus to a descendant haploid.

\begin{defin}
A \emph{haploid lineage} is a set $L$ of haploids such that:
\begin{itemize}
\item distinct members of $L$ have distinct birth times (i.e., are strictly ordered by $\Birth$), and
\item every non-empty subset of $L$ has a newest haploid (i.e., a maximum under $\Birth$).
\end{itemize}
\end{defin}

An equivalent definition is that a \emph{haploid lineage} is a well-ordered set of haploids
under the order of $-\Birth$ (backward in time).

For convenience, we assume \emph{lineage} always means \emph{haploid lineage}.

The empty set $\emptyset$ is the trivial lineage.

\begin{defin}
Let $\Tip(L)$ denote the newest haploid in a non-empty lineage $L$.
\end{defin}

\begin{defin}
For any lineage $L$ with at least two member haploids,
define the \emph{predecessor} of $L$ as
\[
  \Pred(L) := \Tip(L \setminus \{ \Tip(L) \})
\]
\end{defin}

\begin{defin}
For any lineage $L$, a subset $S \subset L$ is a \emph{sublineage} of $L$ iff
\[
\forall x \in L, y \in S \left( \Birth(x) < \Birth(y) \implies x \in S \right)
\mathstop
\]
\end{defin}

\begin{defin}
The \emph{shared lineage} of two lineages $A$ and $B$ is the intersection of $A$ and
  $B$, denoted $A \cap B$.
\end{defin}


\subsection{Lineage Tree}

\begin{defin}
A \emph{lineage tree} is a set $T$ of lineages where,
for all $A, B \in T$, the shared lineage $A \cap B$ is a sublineage of both $A$ and $B$.
\end{defin}

\begin{defin}
A lineage tree $T$ is \emph{complete} if it contains every sublineage $S$ of any $L \in T$.
\end{defin}

The empty set $\emptyset$ is the trivial lineage tree.

\begin{theorem}
  The function $\Tip$ restricted to the domain of a tree (a set of lineages),
  denoted ${\Tip|}_T$, is a one-to-one function.
\end{theorem}

\begin{defin}
For any lineage tree $T$,
let $T_h$ denote a lineage with $T$ as a family of lineages
indexed by haploid $h \in \Haps$ such that
\[
  T_h := \begin{cases}
    {\Tip|}_T^{-1}(h) & \text{if $h \in \{ \Tip(L) \mid L \in T \}$} \\
    \emptyset & \text{otherwise}
  \end{cases}
\]
\end{defin}


\subsection{Stochastic Process}

\begin{defin}
A \emph{haploid lineage process} is a family of lineage-valued random variables,
  indexed by haploids (with subscript) and locus (with superscript),
\[
\{ \Lin^\ell_h : \ell \in \Loci, h \in \Haps \}
\]
where $\{ \Lin^\ell_h : h \in \Haps \}$, denoted $\Lin^\ell$,
 is a complete lineage tree for every $\ell \in \Loci$.
\end{defin}

As a formally defined stochastic process, the index set of a haploid lineage process is
$\Loci \times \Haps$. If one prefers to use $\Time$ as an index set, then one can
consider
\[
  \{ \Lin^\ell_{(t, p)} : \ell \in \Loci, (t, p) \in \Haps = \Time \times \Places \}
\]
as a time-indexed family of random variables that take values as
functions from $\Loci \times \Places$ to lineages.

\begin{defin}
A \emph{haploid death process} is a family of $\Time$-valued random
  variables indexed by haploid (using function notation),
\[
  \left\{ \Death(h) \in \Time \mid h \in \Haps \right\}
\]
such that for all $h \in \Haps$
\[
  \Birth(h) \le \Death(h)
  \mathstop
\]
\end{defin}

\begin{defin}
A haploid lineage process $\Lin$ and a haploid death process $\Death$ are
  \emph{compatible} if and only if,
for all $\ell \in \Loci$ and $h \in \Haps$,
\[
  \Birth(\Tip(\Lin^\ell_h)) \le \Death(\Pred(\Lin^\ell_h))
\]
whenever $\Lin^\ell_h$ has more than one haploid.
\end{defin}

\begin{defin}
A \emph{haploid lineage population process} is a lineage-tree-valued random variable indexed by
  locus and time
\[
  \Tree^\ell_t := \left\{
    \Lin^\ell_h \mid \Birth(h) \le t < \Death(h), \, h \in \Haps
  \right\}
\]
as determined by a compatible haploid lineage process $\Lin^\ell_h$
  and a haploid death process $\Death$.
\end{defin}


\subsubsection{Retro-stationarity}

\begin{defin}
Define $\Shift$ as a function that shifts lineages and lineage trees in time, where
for lineages $L$,
\[
  \Shift(s, L) := \{ (s+t,p) \mid (t,p) \in L \}
\]
and for lineage trees $T$,
\[
  \Shift(s, T) := \left\{ \Shift(s, L) \mid L \in T \right\}
  \mathstop
\]
\end{defin}

\begin{defin}
A haploid lineage population process is \emph{retro-stationary} if
  the lineage-tree-valued stochastic process
\[
  \{ \Shift(-t, \Tree^\ell_t) \mid t \in \Time \}
\]
is stationary for every $\ell \in \Loci$.
\end{defin}


\section{Related Work}
\label{sec:related-work}

\subsection{Kingman $n$-Coalescent}

The Kingman $n$-coalescent \cite{kingman_coalescent_1982} is defined
as a stochastic process terminating at a sample of haploids.
As a time-indexed random variable, the $n$-coalescent takes values
as equivalence relations (partitions) on the samples.

Given a fixed locus $\ell \in \Loci$, and a sample population $S \subset \Haps$,
where for some time $z \in \Time$, for all $a \in S$, $z = \Birth(a)$,
a haploid lineage process defines a backward-time-indexed random
variable $X_r$ that takes the same values as the Kingman $n$-coalescent, but not necessarily
with the same probability distribution.
The value of $X_r$ with $r \in [0, \infty)$ (in reverse time)
is the equivalence relation defined by
\[
  \left\{ (a,b) \in S^2 : \Birth(\Tip(\Lin^\ell_a \cap \Lin^\ell_b)) \ge (z - r) \right\}
\]


\subsection{King Genealogy Tree Processes}

King \cite{king_exact_2026} extends the genealogical tree structure of the Kingman
$n$-coalescent, but with some differences:
\begin{enumerate}
  \item samples need not be at the same time,
  \item partitions are used instead of equivalence relations,
  \item time is indexed forwards, not backwards, and
  \item time zero is fixed to the root of the genealogical tree.
\end{enumerate}

Given a fixed locus $\ell \in \Loci$, a sample population $S \subset \Haps$, a haploid
lineage process defines a \emph{shifted} forward-time-indexed random variable
$Z_s$ that takes the same values as the genealogy tree structure in
\cite{king_exact_2026}.
The time index for $Z_s$ is relative to the root time $R \in \Time$, which is
\[
  R := \Birth\left( \Tip\left( \bigcap_{a \in S} \Lin^\ell_a \right) \right)
\]
and is itself a random variable. With ancestral lineages at time $t$
of the samples $S$ denoted
\[
  A(t, S) := \{ (\infty, t] \cap \Lin(\ell,a) : a \in S \}
\mathstop
\]
we have
\[
  Z_s = \left\{ \{ a : L \subset \Lin^\ell_a \} : L \in A(R + s, S) \right\}
\]
as the tree structure process in \cite{king_exact_2026}.


\subsection{Ancestral Recombination Graph (ARG)}

An ancestral recombination graph \cite{friedman_ancestral_1997}
\cite{hein_gene_2005} \cite{wakeley_coalescent_2009} of a sampled
population is embedded in any outcome of any haploid lineage process.
We formally show the
exact embedding using the gARG formalism \cite{wong_general_2024}.

We start by defining the \emph{genetic legacy} of an ancestral haploid
$h \in \Haps$ for a sample population $S \subseteq \Haps$ to be
\[
  \Lega(h, S) := \{ (\ell, d) \in \Loci \times S : h \in \Lin^\ell_d \}
\mathstop
\]

This genetic legacy is the genetic material that survives in the
sample population $S$ and was originally copied from ancestral haploid $h$
(with or without mutations).

The genetic legacy for a sample population $S$ induces the following
equivalence relation over pairs of haploids $h_1$ and $h_2$ in
$\Haps$:
\[
h_1 \simeq_S h_2 \ := \ \Lega(h_1, S) = \Lega(h_2, S)
\mathstop
\]
We denote the resulting equivalence class containing $h \in \Haps$ as
\[
{[h]}_S \ := \ \{ h' : \Lega(h', S) = \Lega(h, S) \}
\mathstop
\]

In this equivalence relation, haploids are considered equivalent if
they have the same genetic legacy for the sample population $S$.

A convenient choice for an embedded gARG \cite{wong_general_2024} is
to set the gARG nodes (vertices) to be the equivalence classes:
\[
   \Nodes(S) := \{ {[h]}_S : h \in \Haps \}
\mathstop
\]

The (unannotated) graph edges of the gARG are chosen as child-parent
node pairs $(C, P) \in \Nodes(S)^2$ where
\[
  \Pred(\Lin^\ell_h) \in P \text{ for some $h \in C$ and some $\ell \in \Loci$ .}
\]

In the gARG, annotations are added for each graph edge (pair of child
and parent nodes). This annotation is the set of locations through which
genetic information has been copied from parent to child. In the
following interpretation, the only locations of interest are those for
which genetic information has been transmitted into the sample
population $S$. With this interpretation, the annotation for edge
$(C,P)$ is
\[
  \{ \ell \in \Loci :
     C \subseteq \Lin^\ell_h \text{ and } P \subseteq \Lin^\ell_h \text{ for some $h \in S$}
  \}
\mathstop
\]
